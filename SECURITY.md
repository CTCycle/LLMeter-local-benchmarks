# Security Policy

## Supported Versions

Security fixes are accepted for the current `develop` branch and the latest published release tag.

## Reporting a Vulnerability

Do not open public issues for suspected vulnerabilities. Report privately through GitHub private vulnerability reporting when it is enabled for the repository, or contact the maintainer directly with:

- affected version or commit
- operating system and provider used
- reproduction steps
- expected and observed behavior
- any generated report or result file with secrets removed

LLMeter reports may contain local provider URLs, model names, prompts, response previews, and error payloads. Remove sensitive prompts, local paths, tokens, and internal hostnames before sharing artifacts.
